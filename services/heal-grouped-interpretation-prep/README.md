# Grouped interpretation preparation v3

Builds deterministic `llm1_group_payload_v3` artifacts for one `gene + module`
group. The service never calls an LLM.

Inputs:

- `v2_enrichment_module_projection.csv`.
- Optional canonical status table generated by the readiness audit.
- Optional versioned mechanism registry. Only rows with `curation_status=approved`
  and a source are exposed as usable mechanisms.
- Optional run provenance JSON.

Safety rules:

- Identity, VEP and transcript concordance are required for focus eligibility.
- Local UTR/VEP intron discordance is moved to `unresolved_and_failed`.
- SpliceAI uses maximum `DS_*`; a non-empty JSON with zero scores adds no rank.
- GWAS and PharmGKB presence does not add attention points.
- Sparse VCF absence never becomes homozygous reference or callable.
- Outputs are marked `dry_run_only=true`; the API checks `groupPayloadReady`
  before any grouped interpretation step.

The complete per-variant projection remains in
`gene_module_group_variant_detail_v3.csv`. Prompt payloads contain full evidence
only for focus variants and compressed context for the remainder.
